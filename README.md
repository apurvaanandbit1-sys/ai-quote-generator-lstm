# ✨ AI Quote Generator using LSTM

An AI-powered quote generation application built using TensorFlow, Keras, NLP, and LSTM neural networks.

## 🚀 Features

- Generate quote-like text from user prompts
- LSTM-based next-word prediction
- Interactive Streamlit UI
- Download generated quotes
- Generation history tracking
- Cloud deployment using Streamlit

---

## 🛠️ Tech Stack

- Python
- TensorFlow
- Keras
- NLP
- LSTM
- Streamlit
- GitHub

---

## 📊 Model Architecture

Input Text
↓
Tokenization
↓
Padding
↓
Embedding Layer
↓
LSTM Layer
↓
Dense Layer
↓
Next Word Prediction

Input:

The future belongs

Generated:

The future belongs to those who believe in their dreams and never give up
